OpenReplay

                
Senior Software Engineer · R&D · Founding engineer

                
MAY 2022 → NOWParis · open source

                
I have full ownership of the frontend: the replay player, the JS and Swift tracker libraries, the Spot Chrome extension and the MCP apps server. I also work directly with enterprise clients every day.

                
    
                  
  • Cut the main processing pipeline by 40–50% in space and processing time, saving most enterprise clients hundreds of thousands of USD a year.
    • 
                  
  • Rewrote the tracker and player cores. The tracker now uses a versioned binary batch protocol with gzip in a Web Worker; the player core uses shallow observables for CPU efficiency.
    • 
                  
  • Made the frontend bundle ~40% smaller and builds 1–2 minutes faster by migrating from webpack 1 to Parcel and Vite.
    • 
                  
  • Led the full UI rework of the session replayer while keeping legacy support across enterprise deployments.
    • 
                  
  • Shipped offline and conditional recording, feature flags, on-the-fly compression and multi-tab sessions, and moved session heuristics into the browser.
    • 
                  
  • Fixed tracker memory leaks. Set up commit linting, AI PR review, per-module coverage and CI/CD from zero. Shipped under HIPAA, GDPR, CCPA and SOC 2.
